🔒 隐私政策

最后更新：2026-10-21

🌐 English · Русский · 中文
简要说明： Kletka 不收集、不存储、不传输任何您的个人数据。 没有遥测、没有分析、没有跟踪。

1. Kletka 不收集的信息

Kletka 不收集、不存储、不传输：

  • 您的姓名、电子邮件或任何账户信息
  • 您的 IP 地址（除了您提交 issue 或检查更新时 GitHub 看到的）
  • 您打开或编辑的 PGN 文件内容
  • 您分析的局面
  • 您的键盘或鼠标活动
  • 您的位置、语言或系统设置（除本地使用外）
  • 任何使用统计或崩溃报告

2. 本地数据存储

Kletka 在您的计算机上本地存储配置：

  • Windows: %APPDATA%\Kletka\config.properties
  • Linux: ~/.config/kletka/config.properties
  • macOS: ~/Library/Application Support/Kletka/config.properties

该文件仅包含您的偏好设置（语言、棋盘主题、引擎路径、上次打开的文件夹）。 它不会被发送到任何地方。

Kletka 不会 将更新检查结果保存到磁盘。每次检查都在启动时重新进行。

3. 在 GitHub 上报告问题

Kletka 有 "报告问题" 功能（"帮助"菜单）。使用时：

  1. Kletka 在您的浏览器中打开 GitHub 上的新建 issue 表单。
  2. 报告不会自动发送。您可以在提交前查看和编辑。
  3. 需要免费 GitHub 账户才能提交。

3.1. 报告中包含的内容

如果您勾选了 "包含系统信息"（默认启用），以下技术数据会自动预填到报告中：

  • Kletka 版本（例如 1.6.0）
  • 操作系统及版本（例如 Windows 11、Linux、macOS）
  • CPU 架构（例如 amd64、aarch64）
  • Java 版本及供应商（例如 17.0.10、Oracle）
  • 国际象棋引擎名称和版本（例如 Stockfish 16.1，或"未安装"）
  • 界面语言（例如 en_US、ru_RU、zh_CN）
  • 报告时间戳
  • 最大 Java 堆大小

不包含任何个人数据。 您可以在提交前取消勾选此选项。

3.2. 提交后会发生什么

在 GitHub 上点击 "Submit new issue" 后：

  • 报告将在 Kletka 仓库的 Issues 页面上公开。
  • 您的 GitHub 用户名（或"Anonymous"）将可见。
  • GitHub 自己的隐私声明适用于 GitHub 处理的数据，包括您的 IP 地址。

4. 第三方服务

Kletka 本身不连接互联网，除非在以下情况：

  • 自动检查更新（每次启动时 — 见 4.1）
  • 打开链接（GitHub、YouTube、文档）
  • 手动检查更新（帮助 → 检查更新）
  • 报告问题（打开 GitHub issue 表单）

在所有情况下，请求由您的浏览器或 GitHub 基础设施处理，而不是 Kletka 本身。

4.1. 自动检查更新

每次启动 Kletka 时，它会向 GitHub Releases API 发送一个 HTTPS 请求以检查是否有新版本：

  • 地址： https://api.github.com/repos/AndreyKhrypach/Kletka/releases/latest
  • 方法： GET
  • User-Agent 标头： Kletka-UpdateChecker
  • 超时： 5 秒（失败时静默处理）

发送的内容：

  • 您的 IP 地址（任何 HTTPS 请求都会向 GitHub 显示）
  • 标识应用程序及其用途的 User-Agent 字符串

不发送的内容：

  • 任何个人数据（姓名、电子邮件、账户）
  • 任何关于您的 PGN 文件或棋局的信息
  • 任何系统信息（操作系统、Java 版本、语言）
  • 任何遥测、分析、唯一标识符

响应如何处理：

  • Kletka 从响应中读取最新版本号。
  • 如果最新版本比您的版本新，顶部菜单会出现一个小的 🔄 图标。
  • 点击图标将在您的浏览器中打开 GitHub releases 页面。
  • 如果没有更新（或检查失败），则不会出现图标。
退出选项： 更新检查是匿名的，不需要您采取任何操作。 如果您想完全禁用它，可以从源代码构建 Kletka 并禁用 UpdateChecker，或在防火墙中阻止 api.github.com。 GitHub 自己的隐私声明 适用于 GitHub 处理的数据（包括您的 IP 地址）。

5. 国际象棋引擎

Kletka 使用外部 UCI 国际象棋引擎（例如 Stockfish）进行分析。 引擎在您的计算机上本地运行。默认情况下它不连接互联网。

6. 儿童隐私

Kletka 不会故意收集任何人的数据，包括 13 岁以下儿童。

7. 政策变更

如果我们更改本政策，将更新上方的"最后更新"日期。 重大变更将在 CHANGELOG 中公布。

2026-10-21： 添加第 4.1 节，描述自动检查更新功能 （启动时向 GitHub API 发送一个 HTTPS 请求）。

8. 联系方式

有关本政策的问题，请在 GitHub 上开 issue： github.com/AndreyKhrypach/Kletka/issues
