🔒 隐私政策

最后更新：2026-10-06

🌐 English · Русский · 中文
简要说明： Kletka 不收集、不存储、不传输任何您的个人数据。 没有遥测、没有分析、没有跟踪。

1. Kletka 不收集的信息

Kletka 不收集、不存储、不传输：

  • 您的姓名、电子邮件或任何账户信息
  • 您的 IP 地址（除了您提交 issue 时 GitHub 看到的）
  • 您打开或编辑的 PGN 文件内容
  • 您分析的局面
  • 您的键盘或鼠标活动
  • 您的位置、语言或系统设置（除本地使用外）
  • 任何使用统计或崩溃报告

2. 本地数据存储

Kletka 在您的计算机上本地存储配置：

  • Windows: %APPDATA%\Kletka\config.properties
  • Linux: ~/.config/kletka/config.properties
  • macOS: ~/Library/Application Support/Kletka/config.properties

该文件仅包含您的偏好设置（语言、棋盘主题、引擎路径、上次打开的文件夹）。 它不会被发送到任何地方。

3. 在 GitHub 上报告问题

Kletka 有 "报告问题" 功能（"帮助"菜单）。使用时：

  1. Kletka 在您的浏览器中打开 GitHub 上的新建 issue 表单。
  2. 报告不会自动发送。您可以在提交前查看和编辑。
  3. 需要免费 GitHub 账户才能提交。

3.1. 报告中包含的内容

如果您勾选了 "包含系统信息"（默认启用），以下技术数据会自动预填到报告中：

  • Kletka 版本（例如 1.6.0）
  • 操作系统及版本（例如 Windows 11、Linux、macOS）
  • CPU 架构（例如 amd64、aarch64）
  • Java 版本及供应商（例如 17.0.10、Oracle）
  • 国际象棋引擎名称和版本（例如 Stockfish 16.1，或"未安装"）
  • 界面语言（例如 en_US、ru_RU、zh_CN）
  • 报告时间戳
  • 最大 Java 堆大小

不包含任何个人数据。 您可以在提交前取消勾选此选项。

3.2. 提交后会发生什么

在 GitHub 上点击 "Submit new issue" 后：

  • 报告将在 Kletka 仓库的 Issues 页面上公开。
  • 您的 GitHub 用户名（或"Anonymous"）将可见。
  • GitHub 自己的隐私声明适用于 GitHub 处理的数据，包括您的 IP 地址。

4. 第三方服务

Kletka 本身不连接互联网，除非您明确触发：

  • 打开链接（GitHub、YouTube、文档）
  • 检查更新（查询 GitHub API 获取最新版本）
  • 报告问题（打开 GitHub issue 表单）

在所有情况下，请求由您的浏览器或 GitHub 基础设施处理，而不是 Kletka 本身。

5. 国际象棋引擎

Kletka 使用外部 UCI 国际象棋引擎（例如 Stockfish）进行分析。 引擎在您的计算机上本地运行。默认情况下它不连接互联网。

6. 儿童隐私

Kletka 不会故意收集任何人的数据，包括 13 岁以下儿童。

7. 政策变更

如果我们更改本政策，将更新上方的"最后更新"日期。 重大变更将在 CHANGELOG 中公布。

8. 联系方式

有关本政策的问题，请在 GitHub 上开 issue： github.com/AndreyKhrypach/Kletka/issues
