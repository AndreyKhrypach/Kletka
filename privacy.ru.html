🔒 Политика конфиденциальности

Последнее обновление: 2026-10-06

🌐 English · Русский · 中文
Кратко: Клетка не собирает, не хранит и не передаёт никакие ваши персональные данные. Никакой телеметрии, аналитики и отслеживания.

1. Что Клетка НЕ собирает

Клетка не собирает, не хранит и не передаёт:

  • Ваше имя, email или данные аккаунта
  • Ваш IP-адрес (кроме того, что видит GitHub при отправке issue)
  • Содержимое PGN-файлов, которые вы открываете
  • Позиции, которые вы анализируете
  • Активность клавиатуры и мыши
  • Ваше местоположение, язык или системные настройки (кроме локального использования)
  • Любую статистику использования или отчёты о сбоях

2. Локальное хранение данных

Клетка хранит настройки локально на вашем компьютере:

  • Windows: %APPDATA%\Kletka\config.properties
  • Linux: ~/.config/kletka/config.properties
  • macOS: ~/Library/Application Support/Kletka/config.properties

Этот файл содержит только ваши настройки (язык, тема доски, путь к движку, последняя открытая папка). Он никуда не отправляется.

3. Отправка отчёта о проблеме на GitHub

У Клетки есть функция «Сообщить о проблеме» (меню «Помощь»). Когда вы её используете:

  1. Клетка открывает форму новой issue на GitHub в вашем браузере.
  2. Отчёт НЕ отправляется автоматически. Вы можете проверить и отредактировать его перед отправкой.
  3. Для отправки нужен бесплатный аккаунт GitHub.

3.1. Что включается в отчёт

Если вы отметили галочку «Включить информацию о системе» (включена по умолчанию), в отчёт автоматически подставляются следующие технические данные:

  • Версия Клетки (например, 1.6.0)
  • Операционная система и её версия (например, Windows 11, Linux, macOS)
  • Архитектура процессора (например, amd64, aarch64)
  • Версия Java и её производитель (например, 17.0.10, Oracle)
  • Название и версия шахматного движка (например, Stockfish 16.1 или «не установлен»)
  • Язык интерфейса (например, en_US, ru_RU, zh_CN)
  • Время создания отчёта
  • Максимальный размер heap JVM

Никакие персональные данные не включаются. Вы можете снять галочку перед отправкой.

3.2. Что происходит после отправки

После нажатия кнопки «Submit new issue» на GitHub:

  • Отчёт становится публичным на странице Issues репозитория Клетки.
  • Ваше имя пользователя GitHub (или «Anonymous») становится видимым.
  • К обработке данных GitHub применяется их собственная Политика конфиденциальности, включая ваш IP-адрес.

4. Сторонние сервисы

Клетка сама не подключается к интернету, кроме случаев, когда вы явно инициируете:

  • Открытие ссылки (GitHub, YouTube, документация)
  • Проверку обновлений (запрос к GitHub API за последним релизом)
  • Отправку отчёта о проблеме (открывается форма issue на GitHub)

Во всех этих случаях запрос обрабатывает ваш браузер или инфраструктура GitHub, а не сама Клетка.

5. Шахматный движок

Клетка использует внешний UCI-движок (например, Stockfish) для анализа. Движок работает локально на вашем компьютере. По умолчанию он не подключается к интернету.

6. Конфиденциальность детей

Клетка сознательно не собирает данные ни от кого, включая детей младше 13 лет.

7. Изменения в политике

Если мы изменим эту политику, мы обновим дату «Последнее обновление» выше. О существенных изменениях будет объявлено в CHANGELOG.

8. Контакты

По вопросам о политике открывайте issue на GitHub: github.com/AndreyKhrypach/Kletka/issues
