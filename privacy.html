🔒 Privacy Policy

Last updated: 2026-10-06

🌐 English · Русский · 中文
Short version: Kletka does not collect, store, or transmit any of your personal data. There is no telemetry, no analytics, no tracking.

1. What Kletka does NOT collect

Kletka does not collect, store, or transmit:

  • Your name, email, or any account information
  • Your IP address (except as seen by GitHub when you submit an issue)
  • The content of PGN files you open or edit
  • The positions you analyze
  • Your keyboard or mouse activity
  • Your location, language, or system settings (beyond local use)
  • Any usage statistics or crash reports

2. Local data storage

Kletka stores configuration locally on your computer:

  • Windows: %APPDATA%\Kletka\config.properties
  • Linux: ~/.config/kletka/config.properties
  • macOS: ~/Library/Application Support/Kletka/config.properties

This file contains only your preferences (language, board theme, engine path, last opened folder). It is never sent anywhere.

3. Reporting a problem on GitHub

Kletka has a "Report a problem" feature (Help menu). When you use it:

  1. Kletka opens a new issue form on GitHub in your browser.
  2. The report is NOT sent automatically. You can review and edit it before submitting.
  3. To submit a report, you need a free GitHub account.

3.1. What is included in the report

If you check the box "Include system information" (enabled by default), the following technical data is pre-filled into the report:

  • Kletka version (e.g. 1.6.0)
  • Operating system and version (e.g. Windows 11, Linux, macOS)
  • CPU architecture (e.g. amd64, aarch64)
  • Java version and vendor (e.g. 17.0.10, Oracle)
  • Chess engine name and version (e.g. Stockfish 16.1, or "not installed")
  • UI locale (e.g. en_US, ru_RU, zh_CN)
  • Timestamp of the report
  • Maximum Java heap size

No personal data is included. You can uncheck this option before submitting.

3.2. What happens after you submit

Once you click "Submit new issue" on GitHub:

  • The report becomes public on the Kletka repository's Issues page.
  • Your GitHub username (or "Anonymous") becomes visible.
  • GitHub's own Privacy Statement applies to data processed by GitHub, including your IP address.

4. Third-party services

Kletka itself does not connect to the internet, except when you explicitly trigger:

  • Opening a link (GitHub, YouTube, documentation)
  • Checking for updates (queries GitHub API for the latest release)
  • Reporting a problem (opens GitHub issue form)

In all these cases, your browser or GitHub's infrastructure handles the request, not Kletka itself.

5. Chess engine

Kletka uses an external UCI chess engine (e.g. Stockfish) for analysis. The engine runs locally on your computer. It does not connect to the internet by default.

6. Children's privacy

Kletka does not knowingly collect any data from anyone, including children under 13.

7. Changes to this policy

If we change this policy, we will update the "Last updated" date above. Material changes will be announced in the CHANGELOG.

8. Contact

For questions about this policy, please open an issue on GitHub: github.com/AndreyKhrypach/Kletka/issues
